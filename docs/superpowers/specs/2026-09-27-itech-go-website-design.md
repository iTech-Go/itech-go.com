# iTech-Go website redesign — design spec (2026-09-27)

## Goal
Replace the GoDaddy Website Builder site at itech-go.com with a modern, fast, static site
that positions iTech-Go LLC as a senior cloud / data / AI consulting firm serving enterprise
and public-sector clients. Zero incremental hosting cost.

## Constraints (verified 2026-09-27)
- Current site: GoDaddy Websites + Marketing Basic ($203.88/yr, paid through 2027-09-18). No code access.
- No cPanel hosting on the account; adding it costs ~$144/yr at renewal — rejected.
- Domain itech-go.com at GoDaddy (renews 2027-07-27). DNS at GoDaddy. Mail is Google Workspace (must not break MX/SPF).
- Hosting target: GitHub Pages or Cloudflare Pages (both $0). Site must work on either with no build step on the host.

## Approach chosen
Plain HTML + CSS + vanilla JS, generated by a tiny local Python script (`build.py`) that wraps
page fragments in one shared layout. Rejected: Astro/Next (adds toolchain the owner won't maintain);
staying in Website Builder (no custom code, no reviewable local copy).

## Pages
index, about, services, careers, contact, privacy, terms, 404.

## Visual system
- Dark-first theme with light toggle (persisted in localStorage, respects prefers-color-scheme).
- Palette: navy base #0B1020, surface #121A33, text #E6EAF5, muted #9AA5C4, brand blue #3B5BFF → cyan #22D3EE gradient accent.
- Type: Inter Tight (headings), Inter (body) via Google Fonts, system fallback.
- Components: sticky blurred nav, gradient hero, service cards, stat row, 3-step process, tech chips,
  FAQ accordion, CTA band, footer with NAP (name/address/phone), accessible forms.
- Motion: subtle scroll-reveal only; respects prefers-reduced-motion.

## Content
Rewrite all copy in plain English (current About page is machine-paraphrased). Keep verified facts:
iTech-Go LLC, 6751 Dixie Hwy Ste 112, Clarkston MI 48346; +1 (947) 300-1337; accounts@itech-go.com;
Mon–Fri 9–5; open role Sr. Data Engineer (Clarkston, MI). Preserve Privacy/Terms substance, fix
"law of Netherlands" → Michigan, remove generator links.

## Forms
Contact and Careers forms POST to Web3Forms (free tier) using an access key the owner creates;
placeholder key until then, with mailto fallback. reCAPTCHA replaced by honeypot + Web3Forms spam filter.

## SEO / quality
Per-page title/description, Open Graph, canonical, sitemap.xml, robots.txt, JSON-LD LocalBusiness,
semantic landmarks, WCAG AA contrast, Lighthouse target ≥95 on all four categories.

## Deployment (later, after review)
1. Push repo to GitHub, enable Pages (or connect Cloudflare Pages). 2. Add CNAME itech-go.com.
3. At GoDaddy DNS: A records → GitHub Pages IPs (or CNAME → pages.dev), www CNAME. Leave MX/TXT untouched.
4. Verify HTTPS, then optionally cancel Website Builder before 2027-09-18 renewal.
