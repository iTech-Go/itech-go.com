GIS Software Architect

Detroit, MI (on-site, part-time on-site)Full-timeEsri · ArcGIS Enterprise · Utility NetworkAnticipated start early 2027
Apply now

Lead the technical design and execution of a water and sewer utility's migration from the Esri geometric network to the ArcGIS Utility Network, and serve as the senior architect for its enterprise GIS platform.

What you'll do

  • Own the Utility Network migration strategy, readiness assessment, target design (asset groups and types, rules, subnetworks, tiers, terminals), data model mapping, pilot, full migration, validation, and cutover.
  • Design and implement ArcGIS Enterprise and ArcGIS Server configurations for expected load, security, availability, and budget, including HTTP/SSL for web viewers, reverse proxy rules in IIS/ARR, and service performance tuning.
  • Evaluate SaaS and PaaS hosting options and write feasibility and technical recommendation documents.
  • Adapt dependent maps, web applications, and integrations to the new network services and manage controlled release to users.
  • Work with data owners to remediate connectivity, topology, attribute, and domain issues using Python and ArcGIS Data Reviewer.
  • Communicate clearly with stakeholders of widely varying technical background; document solutions, estimate effort, and report status.

Requirements

  • 10+ years of experience with Esri / ArcGIS software across desktop and server technologies.
  • Strong knowledge of ArcGIS Server: installation, configuration, optimization, and publishing of all current service types.
  • 5+ years of advanced expertise with Microsoft SQL Server or Oracle for versioned enterprise geodatabases.
  • Experience planning and managing a company or departmental GIS infrastructure.
  • Hands-on ArcGIS Utility Network design or migration experience; water or wastewater sector experience strongly preferred.
  • Excellent written and verbal communication; able to work on site in Detroit at least two days per week during key project stages.

GIS Software Engineer

Detroit, MI (on-site)Full-timeEsri · Python · Data Reviewer · Web GISAnticipated start early 2027
Apply now

Lead the as-built data program for a water utility GIS: bringing capital-project as-builts and roughly a thousand scanned drawings and permit cards into the GIS accurately, with automated extraction and repeatable quality checks.

What you'll do

  • Update and quality-assure water feature classes (mains, valves, hydrants, fittings, stop boxes) from contractor shapefiles and field data: spatial location, attributes, line-split rules, active/abandoned status, connectivity and topology.
  • QA/QC scanned as-built drawings and permit cards, then script the extraction of key attributes from the images and load and verify results in the geodatabase.
  • Build a standard rule set in ArcGIS Data Reviewer (or similar), run manual QA samples, and write the technical guidance document that accompanies data delivery.
  • Design, implement, test, and monitor integrations with asset management and hydraulic modeling software such as Cityworks and Innovyze.
  • Contribute to web GIS capabilities for real-time and near-real-time data ingestion, spatial analysis, and operational dashboards.
  • Lead workshops for GIS staff on data maintenance and update practices; mentor a GIS intern.

Requirements

  • Degree in geography, urban planning, public policy, computer science, or a related field.
  • 7+ years of hands-on experience developing geospatial technologies: geodatabases, application programming, and project coordination.
  • Strong Python for ArcGIS automation and data extraction; experience with ArcGIS Pro, ArcGIS Enterprise, and versioned editing.
  • Experience with web GIS platforms handling real-time data and large spatial datasets.
  • Water/wastewater or urban planning sector experience preferred; Cityworks or Innovyze exposure a plus.
  • Able to work on site in Detroit, Michigan for scheduled hours.

GIS Analyst

Detroit, MI (on-site)Full-timeEsri · Python · Web mappingAnticipated start early 2027
Apply now

Maintain and improve a utility's water and sewer GIS data alongside the GIS Software Engineer, with a strong hand in Python scripting and web mapping.

What you'll do

  • Edit and quality-check water and sewer feature classes against as-built drawings, field data, and schema standards.
  • Write and maintain Python scripts for attribute extraction, batch updates, validation, and reporting.
  • Run Data Reviewer checks, triage results, and fix connectivity, topology, and attribute issues.
  • Build and maintain web maps, dashboards, and editing applications in ArcGIS Enterprise and ArcGIS Online.
  • Prepare data for the Utility Network migration in coordination with the architect and engineer.
  • Document procedures so GIS staff inherit repeatable processes.

Requirements

  • 5–7 years of GIS experience with a solid grounding in geographic data concepts and Esri tools.
  • Programming experience on the development side of GIS: Python scripting customizations and/or web mapping development.
  • Experience with ArcGIS Pro, enterprise geodatabases, and versioned editing workflows.
  • Careful, detail-oriented approach to data quality; comfortable working from scanned engineering drawings.
  • Able to work on site in Detroit, Michigan for scheduled hours.

Sr. Data Engineer

Clarkston, MIFull-timeAWS · Spark · Python
Apply now

What you'll do

  • Create technical design, source-to-target mapping, and test case documents to reflect ELT processes.
